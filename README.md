# Olist Brazilian E-commerce SQL Project

## 📌 Project Overview

This project analyzes the Olist Brazilian E-commerce dataset using SQL to generate business insights related to sales, customers, products, sellers, payments, and deliveries.

The project demonstrates SQL skills including data analysis, business reporting, aggregation, joins, window functions, CTEs, subqueries, ranking functions, and customer segmentation.

---

## 📊 Dataset

**Dataset:** Olist Brazilian E-commerce Dataset

The dataset contains:

- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Reviews
- Geolocation

## 📌 Key Business Insights

- Credit Card is the most preferred payment method.
- São Paulo contributes the highest revenue.
- High-value customers generate a significant share of sales.
- Delivery performance directly impacts customer satisfaction.
- Top product categories account for a large portion of revenue.
- Repeat customers contribute significantly to overall sales.

---

## 💡 Business Recommendations

- Improve logistics in high-delay regions.
- Reward repeat customers through loyalty programs.
- Focus marketing efforts on high-performing states.
- Increase inventory for top-selling categories.
- Encourage digital payment methods using promotional offers.
